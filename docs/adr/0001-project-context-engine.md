# ADR 0001 — 从"自进化纠错系统"转向"项目上下文引擎"

## 状态

已接受（2026-07-30）

## 背景

EvoKit v0.x 的核心定位是"自进化纠错系统"——通过纠错→观察→晋升→验证→毕业的管线，让 AI 越用越聪明。但随着 AI 模型能力快速提升（Claude 5 Fable/Mythos），这个定位面临根本性挑战：

1. **低级错误减少** — 模型升级后，"用 pip 而非 uv"这类错误极少再犯，纠错管线空转
2. **Claude Code 自带 memory** — 平台已有跨会话持久化机制，EvoKit 的 memory 层与原生能力重叠
3. **系统提示词精简趋势** — 行业趋势是精简而非膨胀，6 个 JSONL 文件 + 5 个钩子的重量级管线与趋势相悖

但 AI 再强也无法获知的项目/个人专属知识，仍然是持久痛点。

## 决策

将 EvoKit 的核心定位从"自进化纠错系统"转向"项目上下文引擎"：

- **核心价值**：持久化 AI 不可能知道的项目/个人专属知识
- **核心机制**：对话提取（AI 识别 + 用户确认）为主，显式声明为兜底，Git 历史为辅助
- **与 Claude Code memory 的关系**：增强而非替代，在 `evokit/` 子目录下工作
- **作用域**：个人 + 项目（团队层搁置）
- **版本**：v1.0.0

### 具体变更

| 维度     | 旧                             | 新                                          |
| -------- | ------------------------------ | ------------------------------------------- |
| 核心定位 | 自进化纠错系统                 | 项目上下文引擎                              |
| 数据文件 | 6 个 JSONL + 2 个 MD           | knowledge-index.md + knowledge/*.md         |
| 存储位置 | 扁平放 memory/                 | memory/evokit/ 子目录隔离                   |
| 知识来源 | 纠错 + 自动观察                | 对话提取 + 显式声明 + Git 历史              |
| 钩子     | 5 个                           | 2 个（SessionStart + Stop）                 |
| 命令     | /boot, /evolve, /evokit-review | /evokit-boot, /evokit-learn, /evokit-review |
| 加载策略 | 全量加载                       | 索引常驻 + 条目按需加载                     |

## 取舍

### 选择对话提取而非自动观察

- **放弃**：PostToolUse 自动追踪编辑模式
- **获得**：更高质量的知识来源，更低的噪声
- **代价**：依赖 AI 的识别能力，可能漏记

### 选择增强 Claude Code memory 而非替代

- **放弃**：独立存储层、完全自主的知识管理
- **获得**：与平台原生能力协同、不与平台对抗、用户无迁移成本
- **代价**：依赖 Claude Code 的 memory 目录结构，其他助手需要同步层

### 选择子目录隔离而非扁平混放

- **放弃**：与 Claude Code memory 文件在同一层级
- **获得**：卸载干净、升级安全、归属清晰
- **代价**：AI 需要同时查询两个位置（通过 knowledge-index.md 桥接解决）

### 选择团队层搁置而非 v1.0 实现

- **放弃**：跨项目团队知识共享
- **获得**：v1.0 范围可控、不违反"隐私优先"承诺
- **代价**：团队约定只能通过项目级知识 + git 提交间接共享

## 迁移策略

现有用户量小，推倒重来：

- `learned-rules.md` → 自动转换 + 手动确认 → 结构化知识条目
- `corrections.jsonl` / `observations.jsonl` / `evolution-log.md` → 归档不迁移
- `violations.jsonl` → 删除
- `sessions.jsonl` → 保留原位
- `rules/*.md` → 保留
- `CLAUDE.md` → 重写
