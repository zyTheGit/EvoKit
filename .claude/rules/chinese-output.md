# 中文优先规则

本项目所有产出优先使用中文，具体范围：

- **Git commit message**：使用中文描述（遵循 conventional commits 格式，如 `feat: 新增卸载命令`）
- **Release notes / Changelog**：使用中文
- **代码注释**：使用中文注释，解释意图和设计决策
- **工具帮助提示（CLI help / usage）**：使用中文
- **文档**：中文为主，英文为辅（双语文档保持 `zh/` + `en/` 结构）

例外：
- 代码标识符（变量名、函数名、类名、文件名）保持英文
- 已有英文惯例的配置字段（如 `package.json` 的 `name`）保持英文
- 用户明确要求英文时，使用英文
