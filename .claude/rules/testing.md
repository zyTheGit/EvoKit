# 测试要求

## 测试门禁

- 改动 `src/` 必须 `npm test` 通过后方可提交
- 新功能必须附带测试
- Bug 修复必须包含回归测试

## 验证流程

1. 修改前：运行现有测试，确认基线通过
2. 修改后：运行全量测试，确认无回归
3. 新增测试：覆盖正常路径 + 边界条件 + 错误路径

## 回归检查

- 修改公共接口 → 检查所有依赖该接口的测试
- 修改配置/常量 → 检查相关测试是否需要更新
- 重构后 → 运行全量测试，不跳过任何测试用例

## 测试质量

- 测试命名描述行为：`should return null for empty input`
- 每个测试只验证一个行为
- 不依赖测试执行顺序，不依赖外部状态
- Mock 最小化：只 mock 外部依赖，不 mock 被测模块内部
