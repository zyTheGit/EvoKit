# 安全规则

## 敏感信息保护

- **禁止硬编码** API key、token、密码 — 使用环境变量
- `.env` 文件权限设为 `600`，不提交到 git
- 日志中不输出敏感数据

## 权限意识

- **禁止直接执行**破坏性操作，必须先说明影响并确认：
  - `rm -rf`、`dd`、`mkfs` 等文件销毁命令
  - `git push --force`、`git reset --hard` 等 Git 破坏操作
- **需确认后执行**：`chmod`/`chown`、API DELETE、数据库变更

## 代码安全

- 禁止 `eval()`/`Function()` 构造器处理动态字符串
- 禁止 shell 命令注入 — 使用参数化 API 而非字符串拼接
- 文件路径操作前验证，防止路径穿越

## 自检

- ✅ 此操作是否破坏性？→ 说明影响，请求确认
- ✅ 是否接受用户输入拼入 shell 命令？→ 使用参数化 API
- ✅ 代码中是否有硬编码密钥？→ 改用环境变量
