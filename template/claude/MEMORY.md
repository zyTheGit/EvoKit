# EvoKit 知识库

- [Memory System Protocol](memory/README.md) — 项目上下文引擎知识库说明

## 知识根

- **个人**：`~/.evokit/knowledge/`（跨项目共享，agent 无关）
- **项目**：`<project>/.evokit/`（随 git 走，可提交）

每个知识根含 `knowledge-index.md`（索引）/ `knowledge/`（条目）/ `.pending/`（待确认草稿）。v0.x 废弃概念（corrections/observations/learned-rules/evolution-log/sessions/violations / evolve）在 v1.0 不再使用。
