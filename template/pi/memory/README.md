# EvoKit Memory Directory

This directory stores learning data for the EvoKit self-evolving system.

## Files

| File                 | Purpose                                 | Permissions |
| -------------------- | --------------------------------------- | ----------- |
| `corrections.jsonl`  | User corrections (append-only)          | 600         |
| `observations.jsonl` | Self-noticed patterns (append-only)     | 600         |
| `learned-rules.md`   | Promoted permanent rules (max 50 lines) | 644         |
| `evolution-log.md`   | Audit trail of evolution decisions      | 644         |
| `sessions.jsonl`     | Session scorecards                      | 600         |
| `violations.jsonl`   | Boot verification violations            | 600         |

## Important

- **Never delete** entries from `corrections.jsonl` or `observations.jsonl` — they are append-only.
- `learned-rules.md` is managed by the `/evokit-evolve` command — do not edit manually unless you know what you are doing.
- Session records are tagged with `"assistant": "pi"` to identify the source.
